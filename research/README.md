# 연구 개요: 순차 구조인가, 병렬 구조인가

## 연구 질문

변동성 예측에서 최근 딥러닝 모델은 범용 벤치마크에서 순환 신경망을 앞선다고 보고됩니다. 그런데 암호화폐처럼 분포가 시간에 따라 바뀌고(비정상), 큰 변동이 몰려서 나타나는(변동성 군집) 자료에서도 그럴까요? 이 연구는 다음 질문에 답합니다.

> 창 안의 시점을 차례로 처리하며 상태를 이어받는 **순차 구조**(GARCH, GRU, LSTM)가 시점을 한꺼번에 처리하는 **병렬 구조**(트리, 어텐션·합성곱 딥러닝, 파운데이션 모델)보다 변동성을 더 잘 예측하는가? 그렇다면 어떤 변동성 국면에서인가?

## 비교한 모델(27개)

| 처리 방식 | 계열 | 모델 |
| :--- | :--- | :--- |
| 순차 | 계량 모형 | GARCH-t, GARCH-BIC(10개 사양 중 BIC로 선택), MS-GARCH, TAR-GARCH |
| 순차 | 순환 신경망 | GRU, LSTM |
| 병렬(특징 기반) | 트리·커널·혼합 | LightGBM, XGBoost, HistGBM, GARCH-BIC+LightGBM, Nystroem+Ridge |
| 병렬(딥러닝) | 어텐션·합성곱·상태공간 | PatchTST, iTransformer, Autoformer, TimeXer, TCN, TimesNet, ModernTCN, S-Mamba |
| 병렬(딥러닝) | 파운데이션(사전학습, 추가 학습 없이 예측) | Chronos-Bolt, TimesFM, TTM, Moirai-2, Sundial, Time-MoE, Lag-Llama |
| 기준선 | 직전 값 | naive(직전 구간 RV를 그대로 예측) |

## 평가 방법

- **손실 함수 QLIKE:** 예측 분산 p̂²와 실제 분산 RV²로 `log p̂² + RV²/p̂²`를 계산합니다. 변동성의 대리 변수에 잡음이 있어도 모델 순위가 뒤바뀌지 않는 성질이 있어 변동성 예측 비교에 널리 쓰입니다. 값이 작을수록 좋습니다.
- **우열 판정:** 두 모델의 손실 차이를 시각마다 구해 그 평균이 0과 다른지 검정합니다(Diebold–Mariano 검정). 비교가 많으므로 Holm 보정으로 우연히 유의하게 나오는 경우를 줄입니다.
- **국면:** 예측 시점에 이미 아는 직전 변동 폭으로 다섯 국면(Q1 가장 잔잔 – Q5 가장 요동)을 나눠, 국면마다 따로 비교합니다([발견 5](findings/05_ex_ante_regimes.md)).
- **시드:** 신경망처럼 학습 시드에 따라 결과가 흔들리는 모델은 시드 20개로 반복하고, 그 흔들림을 표준오차에 넣습니다([발견 7](findings/07_seed_variance_in_se.md)).

## 핵심 결과

1. 다섯 구간 모두 1위는 기존 모델이었습니다. 15분·30분은 GARCH-BIC, 1시간·4시간은 GARCH-BIC+LightGBM, 12시간은 Nystroem+Ridge입니다. 새로 넣은 병렬 딥러닝·파운데이션 모델 15개는 어느 구간에서도 1위를 넘지 못했습니다.
2. 가장 요동하는 국면(Q5)에서 순환 신경망은 병렬 딥러닝보다 다섯 구간 모두 유의하게 나았습니다. 자료를 한 번도 보지 않은 과거 독립 기간에서도 학습형 병렬 딥러닝 8개가 이 국면에서 1위보다 나쁘다는 판정이 재현되었습니다(40쌍 중 37쌍).
3. 같은 입력을 주면 이 차이는 구분되지 않았습니다. 순환 신경망의 우위는 구조 자체보다 15분봉 경로를 입력으로 받는 데서 주로 왔습니다([발견 6](findings/06_sequential_advantage_input.md)).
4. 실무 권고: 변동성 예측은 GARCH와 순환 신경망 같은 순차 기준선에서 시작하고, 구조를 바꾸기 전에 입력 표현을 먼저 바꿔 봅니다. 국면에 따라 모델을 바꿔 쓰는 방식은 권하지 않습니다(전체 기간 1위가 요동 국면 1위와 통계적으로 구분되지 않았습니다).

## 연구 중에 확인한 발견

각 문서는 "무엇이 궁금했나, 무엇을 확인했나, 그래서 무엇을 정했나" 순서로 씁니다.

| 번호 | 발견 | 결정 |
| :--- | :--- | :--- |
| [1](findings/01_direction_vs_magnitude.md) | 방향은 거의 예측되지 않고 변동 폭은 예측된다 | 변동 폭(실현변동성)을 예측 대상으로 정함 |
| [2](findings/02_nonlinearity.md) | 선형 회귀의 선형성이 대부분 종목에서 기각된다 | 비교 대상을 비선형 모델로 한정 |
| [3](findings/03_two_part_halts.md) | 짧은 구간일수록 가격이 멈춘 구간이 많다 | 정지 확률과 정지가 아닐 때의 변동 폭을 나눠 예측 |
| [4](findings/04_retransformation_bias.md) | 로그로 학습한 예측을 되돌리면 짧은 구간에서 크게 과소 예측한다 | 구간마다 보정 배율을 추정해 곱함 |
| [5](findings/05_ex_ante_regimes.md) | 같은 국면에 머무르는 경향이 잔잔할 때와 요동할 때 모두 강하다 | 예측 시점에 아는 직전 변동 폭으로 국면을 나눠 평가 |
| [6](findings/06_sequential_advantage_input.md) | 요동 국면의 순환 신경망 우위는 입력을 맞추면 사라진다 | 구조보다 입력을 먼저 바꾸도록 권고 |
| [7](findings/07_seed_variance_in_se.md) | 시드 흔들림을 빼면 거짓 유의가 두 배 넘게 늘어난다 | 시드 분산을 표준오차에 넣고 시드 수를 규칙으로 정함 |

## 계산 비용

RTX 4090 한 장과 CPU 4스레드 기준으로, 성적이 좋은 모델(GARCH-BIC, 트리, 순환 신경망)이 학습 비용도 가장 낮은 편이었습니다. 종목·시드 하나에 다섯 구간 모두를 학습하는 데 약 3–30초가 걸렸고, 가장 오래 걸린 TimesNet은 약 860초였습니다. 가장 느린 예측 모델도 예측 한 번에 약 4ms여서 15분 주기 운용에는 제약이 되지 않습니다.

## 한계

- 결론은 15분봉, 이 20종목, 종가 기준 RV와 QLIKE 손실 조건에서 나온 것입니다. 거래대금과 변동성이 중간인 종목은 시험하지 않았습니다.
- 분산 그대로의 오차(MSE)로 채점하면 대부분 모델이 서로 구분되지 않아, 권고는 QLIKE 기준으로 읽어야 합니다.
- 신경망 입력 길이와 구조 설정은 고정했습니다. 입력 길이를 바꾼 재학습은 진행 중입니다.
